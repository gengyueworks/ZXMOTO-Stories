# 如何评价张雪没有通过高考上大学却做出了一流的机车？

> 来源：知乎专栏「张雪机车 | 极致热爱」
> 作者：耿悦

「不会就学啊。」

「你初中毕业，然后你学修车，你怎么能把发动机干成这样？」

这句话触发了我。我去翻了他的采访，想看看这背后到底是什么逻辑。

他对摩托车钻得有多深？

「我对发动机的结构、原理，了解得像了解自己的身体、皮肤一样。我现在闭上眼，我自己都可以设计发动机。

我拆解了无数发动机。就是我把眼睛蒙起来，所有的部件拿过来，我蒙着眼睛，照样能装。」

修车完全靠自学起步。20岁左右，他就能练到”蒙眼从一堆零件里装回一台发动机”。这已经不只是熟练工，是神级技能了。

长期泡在一线拆装、实战，他敢说”老的、新的，我自己都可以设计”，说明他对原理、结构、受力、工艺的理解已经是贯通的，不是只会”改装几下”。

在他的采访里，你能看到很多技术细节，隔着屏幕都能感到那种对摩托车心无旁骛的热爱。但他又不停在强调：要不停学习。

一个没上过学的人，照样能把世界一流的机车做出来，那读书还有什么用？

要回答这个问题，你得顺着他的成长脉络往回看。

他的学习路径其实很野生：

少年时期，湖南卫视拍他纪录片那会儿，他在自己开的修车铺里，整天和坏掉的摩托车打交道。别人看来是一堆油腻的零件，对他来说就是最早的”课本”。

发动机怎么拆、哪里最容易磨损、什么结构一看就知道设计得不行，他就是在一台台拆、一台台装回去的过程中，把最基础的机械常识和“车感”一点点攒出来的。

这些辛苦钱，别人大多会拿去犒劳自己，吃点好的、买点贵的。

他挣到的第一笔钱，直接去买了一辆本田，把整车拆开，研究零件和构造。这一整套”发动机解剖课”，未必比你在课堂上翻几本教材差。

后来纪录片播出后，真的有车队看到他，他进了越野车队，做了赛车手兼机械师。

前台后台全包，都是无穷无尽的调试和试错：悬挂软硬一点点调，胎压一格一格试，齿比来回换，找出进弯和出弯最顺手的组合。

每一次摔车、每一次机械故障，都是一堂课。比上学苦很多，不仅赚不到钱，还是真刀真枪飞驰加摔车，动不动就伤筋动骨、报废整车。

在这个阶段，他学到的是”车在极限工况下会怎么表现”。这种东西，书本上几乎给不了。

再后来，他进了浙江的摩托车厂，从一线工人做起。焊接车架、盯喷涂、跟着师傅做总装，学的是”整车从图纸到落地”的全流程。

以前他只知道”这地方容易坏”，现在开始明白”为什么会坏””怎么在设计和工艺上避免它坏”。

这一部分，已经非常接近正规的工程教育，只是他的课堂在车间，老师是工艺工程师，教材是质检报告。

到创立凯越的时候，他完成了从“会修车、会调车”到“会定义一台车”的跨越。

排量怎么定，目标用户是谁，用什么发动机平台，预算卡在哪里，这些都是设计之外的“商业课”。

一台车在图纸上很好看，在样车阶段很好骑，不代表能量产、能赚钱。

和合作伙伴一起去把产品线拉出来，把供应商体系搭起来，踩了无数质量、成本、交期的坑，这些都是商业维度最真实的历练。

从教育的角度看，这一长串经历，几乎就是一套完整的”野生工科＋商科”课程：结构、工艺、产品、市场，缺一不可。只是所有课都得靠他自己去找，所有考试都是真金白银，用命在折腾。

你上学花四年时间，系统学一些基础理论；

他是用十几年、一堆失败，没日没夜浸泡在那一亩三分地里，用双手和零件互相打磨。

张雪是"在传统学历体系里不完整，但在自己领域里长期高强度学习和实践"的人。

如果把“上学”和“实践”拆开看，大概这么理解：

读书给你一张地图，告诉你这条路大概往哪走。

像张雪这样，就是手里没有地图，但天天在走路。

天天都出现在这条路上，不断地走，这个路况你绝对非常清楚。

地图可能是十几年前画的，很多路径今天已经失效了；

而那个每天都在走路的人，脑子里自然会长出一张最新的地图。

是真实版本的：哪段路很不好走，哪条小路里有个小门，哪里有条没人标出来的捷径，哪里其实有漏洞。

一个每天都在趟这条路的Explorer，反而握着第一手的信息。

他日复一日踩出来的那条线，才是最新鲜、有生命力的地图。

最理想的状态，其实是两样都有。

张雪走的是一个极端版本：他一开始手里没有地图，一路磕磕绊绊地自己试、往前闯。

如果有机会，他能一边实践，一边系统学到知识，那不是更好？

你带着实践里的问题和不解走进课堂，很多知识其实都是对你困惑的”底层逻辑解答”，那会更爽。

一个带着问题和思考的人去学，和被动填鸭式地听课，差别非常大。

读书的意义在哪？你可以在一个相对安全的环境里，系统地建立基础：力学、材料、机械原理、控制、统计等等。

如果你学过发动机原理，再去修理铺拆发动机，你会更快看懂那些设计决策；如果学过一点工程管理，再去工厂做项目，你会更快判断问题是出在设计环节、供应链，还是过程控制。

你有了这方面的知识积累，如果想要入行，也会相对容易些，不会完全没有门路。

反正学校给的是”地图”和”如何使用工具”的方法，真正的使用，得和实践结合。

像张雪那样，没有地图、凭自己硬生生蹚出来一条路，代价极高，夭折的概率很大。

他能走通，是因为他一直在练，一直在学，但这条路线本身就是高难度模式。

对绝大多数人来说，先拿一张还算靠谱的地图，再下地走路，是更现实的选择。

能够有条件读书还是享受读书啊。

但他用一辈子证明的，是长期、专注实践的力量：

选择你所热爱的，或者认准一件事，

持续地动手、犯错、修正、再动手，在一个方向上钻透。

学校教育的最佳用法，是让你在进入实践之前，先有足够的工具和视野，然后尽早把这些东西扔进真实世界里去碰撞。

张雪是那种彻底的实干型，对”把这件事干到极致”近乎有强迫症。

他绝对是个长期学习者。

还看到一个他在机场想摩托车技术问题，终于想通了，发现飞机都飞走了，在欧洲人生地不熟，在机场发的搞笑自嘲视频。

听了几个他的开会录音，他不是那种只会喊口号的老板，大部分时间都在讲技术细节：

他会冲到生产、质量一线，掰着具体零件、误差、模具、夹具的细节，给厂里的人一条一条纠正。

比如有人问怎么检查”跳动”（轴类零件装配后的偏心、振动），他回答要装好以后慢慢手动转，用表实际去测跳动。

坏的模具要修，夹具要改，不能只是强行”攻几下””硬压进去”就当合格。

他对质量有极端要求，在质量会上永远站在最”较真”那一侧，对”凑合””差不多就行”极度不耐烦。

很欣喜地看到，他的学习态度也很开放。

他们也强调团队的力量，会主动去找更专业的工程师，把有经验的人拉进来一起干。

他清楚地知道：要把平台级发动机和世界级赛车做好，只靠一个人的能力去拼命不行，必须让车间、工程、质检、供应商等环节都参与进来，按统一标准反复练，把整条链路的能力一起拉上去。

他对学习，是”不会就学”、拆到可以盲装的那种狠劲。

当探索到自己的边界，也愿意承认”我们搞不定就去找更强的人”，愿意承担由此带来的资金压力和责任结果，愿意为此付钱，孤注一掷。

他说过一句话：

“只要你真的喜欢，真的想做，又肯下功夫，怎么可能做不出来？不会的可以去学，关系也可以慢慢建立，关键是你愿不愿意去做。”

在自己真正想做的那件事上，他会把所有能用的资源都砸进去。是一种极致学习与践行的组合。
