# ZXMOTO Stories

> 张雪机车拿世界冠军那阵子，我刷了一圈中文媒体，发现一个怪事：新闻全是通稿，标题党几句「震惊」「碾压」，正文连比赛发生了什么都说不清楚。
>
> 一个没通过高考的中国人，带着一帮人，把国产机车送上了世界赛场，跟百年老厂同台较量。这是这几十年里最燃的中国制造故事之一。可没人好好写。
>
> 那我写。

## 关于

ZXMOTO Stories 记录了张雪机车从造车到夺冠的故事——创始人、车手、工程师，以及那些把不可能变成可能的人。

所有文章来自知乎专栏「张雪机车 | 极致热爱」，作者耿悦。每篇都按真实创作日期标注。
