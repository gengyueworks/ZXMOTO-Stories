# ZXMOTO Stories

2026 年，一家成立没几年的中国摩托车厂，在世界超级摩托车锦标赛上一个赛季拿下七个分站冠军——对手是雅马哈、杜卡迪这些百年厂商。

这件事放在几年前，没人敢想。

这里收的是这段历史：从怀化的修车铺到世界领奖台，那些人怎么把不可能一步步走成可能。
